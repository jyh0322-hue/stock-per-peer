# 화면 설계서 (UI Design) — DART 종목 PER·PEER 분석 웹앱

- 작성일: 2026-08-14
- 시안 파일: [`ui-mockup.html`](./ui-mockup.html)
- 관련 문서: [설계서](../superpowers/specs/2026-08-14-dart-peer-per-web-design.md) · [구현 계획서](../superpowers/plans/2026-08-14-dart-peer-per-web.md)

단일 페이지(SPA) 구성. 하나의 화면에서 **검색 → 진행 → 결과** 3개 상태가 전환된다.

---

## 화면 상태 흐름

```
[검색] --분석 클릭--> [진행(진행바+5단계)] --완료--> [결과]
   ▲                                              │
   └──────────── 새 종목 재검색 ──────────────────┘
   └─ 종목 미발견/오류 시: 검색 화면에 에러 배너
```

| 상태 | 트리거 | 표시 |
|---|---|---|
| 검색 | 첫 진입, 결과에서 재검색 | 검색창·예시 태그 |
| 진행 | `POST /api/analyze` 성공(job_id) | 진행바 + 5단계 체크리스트 |
| 결과 | `status=done` 후 `GET /api/result` | KPI·PEER표·PER차트·공시 |
| 에러 | 400(미발견)·잡 error | 검색 화면 상단 빨간 배너 |

---

## 상태 1 · 검색 화면

**목적**: 종목명 한 개 입력.

**구성요소**
- 타이틀 `📊 종목 PER·PEER 분석` + 한 줄 설명(무엇을 계산하는지)
- 검색 입력창(placeholder: `종목명 입력 (예: 브이티, 삼성전자, 코스맥스)`) + `분석` 버튼
- 인기/예시 검색 태그 pill (클릭 시 입력창 자동 채움)

**동작**
- Enter 또는 `분석` 클릭 → `POST /api/analyze {name}`
- 빈 입력 → 제출 무시
- 400 응답 → 입력창 아래 에러 배너에 `detail`(유사 후보 포함) 표시

---

## 상태 2 · 분석 진행 화면

**목적**: 30초~1분 소요되는 비동기 분석의 진행을 시각화(멈춘 것처럼 보이지 않게).

**구성요소**
- 상단: 검색어 고정 표시(readonly 입력창)
- 진행바(0→100%), 캡션 `<현재 단계명> · N/5 단계 (pct%)`
- 5단계 체크리스트 — 상태별 아이콘
  - 완료: ✓ (초록)
  - 진행중: 스피너 (파랑, 굵게)
  - 대기: · (회색)

**5단계 매핑** (백엔드 `progress_cb`와 1:1)
1. 종목 해석
2. 업종·시총 조회
3. PEER 실적 수집 (`(current/total)` 서브카운트 표시)
4. PER 계산
5. 공시·결과 조립

**동작**
- `GET /api/status/{job_id}` 1.5초 폴링 → `progress.pct`로 바·캡션 갱신
- `state=done` → 결과 조회 후 상태 3 전환
- `state=error` → 검색 화면 + 에러 배너

---

## 상태 3 · 결과 화면

**목적**: PER 한 눈 파악 + 업종 대비 위치 + 근거(표·차트·공시).

### 3-1. 헤더
- 종목명 + 종목코드(회색) + 업종 chip(`업종 · 화장품`)

### 3-2. KPI 카드 (4개, 데스크톱 4열 / 모바일 2열)
| 카드 | 값 | 비고 |
|---|---|---|
| 시가총액 | `3,200 억` | |
| 최근 분기 영업이익 | `85 억 (2026 반기)` | 보고서 기준 표기 |
| **PER(영업이익·연환산)** | `9.4 배` | **강조(붉은 카드)** + 중앙값 대비 코멘트 |
| 업종 내 순위 | `4 / 6` | "PER 낮을수록 상위" |

- PER 카드는 타깃 강조색(`--target`) 배경. 중앙값 대비 저평가=초록/고평가=주황 코멘트.

### 3-3. 업종 PEER 비교표
- 컬럼: 종목 · 시총(억) · 최근분기 영업익(억) · 연환산(억) · **PER(영업이익)** · KRX PER
- PER **오름차순** 정렬, 타깃 행 `★` + 강조 배경
- PER 셀: 중앙값 미만=초록, 크게 상회=주황(선택적 badge)
- 적자 종목: `N/A(적자)`

### 3-4. PER 비교 차트
- 가로 막대(CSS/이미지) — 종목별 PER, 타깃 막대만 강조색
- 업종 중앙값 점선 오버레이 + 라벨
- (구현) 백엔드 `chart_per_b64`(matplotlib PNG)를 `<img>`로 렌더 — 시안은 CSS 막대로 표현

### 3-5. 최근 공시
- 리스트: 날짜 · 제목 · 유형 태그 · 회사명(타깃/PEER)
- 유형 태그 색: 정기공시(회색)·주요사항(주황)·발행공시(보라)·기타(연회색)
- 최근 90일, 상위 20건

### 3-6. 면책 고지
- 자동 집계·투자자문 아님 + PER 산식 각주

## 반응형

| 구간 | 처리 |
|---|---|
| ≥ 720px | KPI 4열, 표 전체 표시 |
| < 720px | KPI 2열, 표 가로 스크롤(`overflow-x`), 차트 라벨 축약 |

- 본문 최대 폭 1080px 중앙 정렬.
- 표는 항상 자체 가로 스크롤 컨테이너 안에서 넘침 처리(페이지 가로 스크롤 금지).

## 디자인 토큰 (라이트/다크 공용)

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--bg` | `#f4f6fb` | `#0d1017` | 페이지 배경 |
| `--panel` | `#ffffff` | `#151a22` | 카드/프레임 |
| `--fg` | `#111827` | `#e6e9ef` | 본문 |
| `--muted` | `#6b7280` | `#9aa3b2` | 보조 텍스트 |
| `--brand` | `#1d4ed8` | `#5b8cff` | 강조/버튼/헤딩선 |
| `--target` | `#e11d48` | `#fb7185` | 타깃 종목 강조 |
| `--good` | `#059669` | `#34d399` | 저평가/완료 |
| `--warn` | `#d97706` | `#fbbf24` | 고평가/경고 |

- `prefers-color-scheme`로 다크모드 자동 대응.
- 숫자는 `font-variant-numeric: tabular-nums`로 자릿수 정렬.

---

## 접근성 · UX 원칙

- 진행 화면으로 "멈춘 화면" 방지 — 항상 현재 단계·퍼센트를 명시.
- 색만으로 정보 전달 금지 — 타깃은 `★` 기호 + 색, 저/고평가는 텍스트 코멘트 병기.
- 에러는 조용히 실패하지 않고 배너로 사유(유사 후보 포함) 노출.
- 모든 금액 단위(억)·PER 단위(배)를 값 옆에 명시.
